# NEXUS - Code Awakening

NEXUS is a coding challenge game designed to help students practice
programming and technical interview concepts through interactive questions.

## Features

- Interactive coding questions
- Multiple-choice answers
- Score calculation
- Percentage calculation
- Performance feedback
- Simple command-line interface

- Python
- Git
- GitHub
